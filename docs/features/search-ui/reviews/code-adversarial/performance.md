## Stance

High-signal panel with one over-reach. The three ranked findings all survived independent verification: PC-2's collation dup is real at the byte level (en_US.UTF-8 default collation, uncollated id columns, 16/38 diverging `faith` tie-groups, JS/SQL disagree on the exact cited pair); PC-1's full-page crash is empirically reproduced on the live worker (the `.data` 400/500 path carries `x-remix-response: yes`, so the error body lands in `fetcher.data` and the unguarded `d.groups.find` throws into the ErrorBoundary); PC-3's 18.5 kB-gz dead-drizzle chunk is present in the shipped build and imported by the `/search` route chunk. PC-4/PC-5/PC-7 are genuine low/residual defects — PC-5 and PC-7 are correctly framed as residuals of the fixed B-U1/B-U2 modes at new sites, not re-flags of the fixed instances.

The single miss is **PC-6**: it re-litigates the ratified PU-6 row-render disposition ("revisit only if telemetry") from a "typing" rather than "scroll" angle, but supplies no measurement and its meaningful cost lands at the same deep-append tail PU-6 already dismissed — noise. No finding is *risky*: PC-2's `COLLATE "C"` pin is free (EXPLAIN shows top-N heapsort, no index dependency) and merely aligns SQL with the JS/cursor order it already mints against; the other fixes are contained one-liners. No finding is out-of-scope — none touches the deliberate-Out list, and PC-3's bundle cost is on this feature's own route.

Dissent rate: 1/7 (0.14). No high/med finding downgraded.
