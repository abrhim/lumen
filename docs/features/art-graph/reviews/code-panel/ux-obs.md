## Verified compliant (no issue found)

- **Stack is one ≥44px focusable element (amendment 1):** `ChapterArtStack`'s `Link` carries `min-h-11` (Tailwind's `11` = 2.75rem = exactly 44px) plus vertical padding, so the rendered target is ≥44px; it is the sole interactive element (inner `<span aria-hidden="true">` wraps all `ArtImage` thumbnails, correctly hiding decorative images from the accessibility tree).
- **Stack aria-label wording:** `` `View ${art.length} artwork${...} for ${reference}` `` matches amendment 1's spec exactly and correctly pluralizes.
- **Header height diff when art is absent is acceptable:** `ChapterArtStack` returns `null` for zero art (same short-circuit as the old `ChapterArtStrip`); the new stack's `h-14` (56px) thumbnails are shorter than the old strip's `h-36` (144px) blocks, so the with/without-art layout delta is smaller than before, not a regression.
- **Gallery grid aspect-ratio boxes (amendment 2):** `aspect-[4/3]` + `overflow-hidden` fixed boxes prevent CLS on image load; grid items map in loader (fame-ranked) order with no `tabIndex` overrides, so tab order matches visual/DOM order for all cards that do have an href.
- **Back link preserves `?verse` on both header links (amendment 3):** both the arrow-icon `Link` and the `{bookId} {chapter}` `Link` in the `<h1>` point at the same `backUrl`, which appends `?verse=${verse}` when present.
- **Alt text on gallery/stack images:** `ArtImage`'s `alt` correctly composes `title` (+ `— artist` when present); shared component keeps this consistent across stack, gallery, and (previously) the strip.
- **Empty vs degraded copy distinct:** degraded → "Artwork couldn't be loaded right now — try again in a moment."; empty → "No artwork has been indexed for this {unit} yet." — different tone and wording, not confusable.
- **art_gallery_404 cause taxonomy:** `unknown_book`/`invalid_chapter` match the sibling `scripture_404` cause vocabulary exactly (same strings), good cross-route consistency for the causes it does cover (see CUO-7 for the one gap).
- **Smoke canary assertions are readable:** `smoke-art-edges.mjs` checks use descriptive names + inline detail strings (e.g. "Rembrandt Simeon DEPICTS luke-2"), consistent ✓/✗ output, pinned to specific live-probed ids — easy to diagnose a failure from output alone.
- **Motion:** the only new transition is `transition-colors duration-150` (stack hover, gallery back-link hover) — a color-only transition, not a transform/motion animation, so no `motion-reduce` gate is required per the SKILL's decision flow; no fan/scale animation was added, matching amendment 1's "static" requirement.
