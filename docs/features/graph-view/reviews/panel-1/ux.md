# Panel 1 — UX review: graph-view

| ID | Severity | Where | Problem (≤ 25 words) | Fix (≤ 30 words) |
|---|---|---|---|---|
| UX-1 | high | Mobile entry point (verse panel opens graph button lives inside the `?verse` bottom sheet) | `?verse` Sheet and `?graph` overlay can both be mounted at once — two portaled dialogs, two backdrops, two focus traps, ambiguous Esc target. | Make the params mutually exclusive: opening the graph closes the sheet (drop `?verse` or keep it inert underneath, hidden from a11y tree). |
| UX-2 | high | Overlay initial load (`React.lazy` chunk + deferred `getNeighborhood` promise) | Plan defines a skeleton for the verse panel (`ConnectionsSkeleton`) but not for the graph — no spec for what a loading *graph* looks like before nodes/positions exist. | Define a graph skeleton: pulsing center node + faint ring placeholders on the mock's radial parchment gradient, matching `ConnectionsSkeleton`'s `aria-busy` pattern. |
| UX-3 | med | Depth segmented control (1/2/3) | Switching to a bigger depth on a hub entity re-triggers the loader with no in-progress signal — user can mash depth buttons or think the click didn't register. | Disable the depth segment and dim the current graph (not blank it) while the new depth's promise resolves; re-enable on settle. |
| UX-4 | med | `truncated: { shown, total }` from `getNeighborhood` | No UI location is defined for truncation copy — the mock has no "N of M" text anywhere in `LocalGraph`'s header/legend/footer, only a `+N` node stub. | Add a persistent line near the depth control, e.g. "Showing 50 of 213 connections — narrow with depth," always visible when `shown < total`. |
| UX-5 | high | `.lm-gnode.click:hover circle` recenter affordance (ForceLayout/GraphCanvas, ~line 566-568) | Recenterable vs. decorative nodes are distinguished only by a `:hover` stroke change, ungated by `@media(hover:hover)` — touch users get no cue before tapping, and the highlight can stick after tap. | Give recenterable nodes a persistent visual cue (ring, dot, or subtle glow) independent of pointer type; reserve hover for a secondary desktop-only affordance. |
| UX-6 | med | "Read this verse" / "Read →" jump (~line 621, plan §Web overlay) | Plan doesn't state whether the verse jump pushes or replaces history — user closing the verse view via Back may or may not land back in the graph they were exploring. | Specify push navigation for the Read jump (consistent with recenter's Q5 "push" default) and surface a hint that Back returns to the graph. |
| UX-7 | low | Failure-mode coverage (plan §Failure modes 1-9) | Only "unknown entity" (`found:false`) and "degraded" states have defined copy; a legitimate zero-connection node (`found:true`, empty neighbor list) has no distinct empty-state message. | Add explicit empty-neighborhood copy, e.g. "No connections recorded within depth {N} for this collection set," distinct from not-found/degraded text. |
| UX-8 | med | Legend (`TYPE_LEGEND`, line 199) vs. plan §Entity breadth | Plan adds Era, Event, Symbol, Topic/NaveTopic node types that don't exist in the mock's `TYPE_LEGEND` map and aren't self-explanatory (what's an "Era" node vs. a chapter?). | Write plain-language legend labels/one-line tooltips for every new type before ship (e.g., "Topic" not "NaveTopic", "Time period" for Era). |
| UX-9 | med | `ForceLayout` re-seed on topology change (line 581-599) | Growing depth (1→2/3) reruns the simulation from a fresh radial seed each time, so already-visible depth-1 nodes the user was tracking jump to new positions. | Seed the new simulation with prior `{x,y}` for node ids that persist across the depth change; only new nodes enter from the radial default. |
| UX-10 | low | Overlay close (Esc/backdrop/✕) and its three entry points (verse-panel button, principle/people chip, chapter-header button) | Plan states focus is "trapped and restored" but not restored *to what* — three different triggers exist, and none is tracked for refocus. | Store a ref to the invoking control on open; on close, return focus and (where applicable) scroll position to that exact element. |
